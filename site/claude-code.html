Integration

Space3d for Claude Code

Start from zero: install the tools, scaffold a game, and let Claude build it with the engine's rules and the build–test–look loop. There are no prebuilt binaries yet, so the space3d CLI is built from source (a few minutes, once). Plain-text version for agents: /claude/SETUP.md.

Paste this into Claude Code

The fastest way: replace <YOUR GAME IDEA> and paste the whole block into Claude Code in an empty folder. It installs what is missing, scaffolds the game and builds your idea.

I want to build a game with the Space3d engine (Rust). My idea: <YOUR GAME IDEA>

Do this, and tell me what you ran and what happened:

1. Learn the engine. Read https://space3d.dev/llms-full.txt (the README and all docs in one
   file). If you cannot fetch URLs, use the public repository instead:
   https://github.com/SpaceCorps/Space3d (clone it, read README.md, docs/getting-started.md and
   integrations/claude-code/).
2. Check the tools. You need git and Rust 1.98 or newer (`rustup update stable`). If
   `space3d --version` fails, install the CLI (a few minutes, it compiles from source):
   cargo install --git https://github.com/SpaceCorps/Space3d space3d-cli
   Then run `space3d doctor` and apply the fixes it prints.
3. Scaffold. Run `space3d new <snake_case_name> --template 3d` (templates: basic, 3d,
   multiplayer) and cd into it. Save https://space3d.dev/claude/AGENTS.md as AGENTS.md and
   create CLAUDE.md containing the single line @AGENTS.md
4. Build my idea in src/lib.rs. After every change add or extend a test in tests/ and run
   `space3d test`. Finish with `space3d run --headless --frames 120` and look at a screenshot.

Never open a window that steals my focus: use headless runs. Do not say it is done until
`space3d test` is green; show me the output.

Or do it by hand

  1. Prerequisites

    Rust 1.98 or newer, git and a C linker. space3d doctor (step 3) tells you anything else that is missing.

    rustup update stable      # install rustup from https://rustup.rs first
git --version
# Windows: Visual Studio Build Tools, "Desktop development with C++"
# macOS:   xcode-select --install
# Linux:   gcc or clang, and pkg-config

  2. Install the CLI

    Builds the space3d tool from source. This takes a few minutes the first time.

    cargo install --git https://github.com/SpaceCorps/Space3d space3d-cli
space3d --version

  3. Check the machine

    Lists what is installed for each platform (desktop, web, Android, iOS) and prints the exact command for anything missing, such as the wasm target.

    space3d doctor

  4. Install the plugin (optional)

    Adds the space3d-game skill: scaffold, the edit → test → screenshot loop, and the engine's hard rules (fixed tick, never block the frame, wasm-clean). The AGENTS.md in step 5 carries the same rules without it.

    /plugin marketplace add SpaceCorps/Space3d
/plugin install space3d@space3d

  5. Scaffold a game

    Templates: basic, 3d, multiplayer. Then give Claude the rules: the template · the skill.

    space3d new asteroids --template 3d
cd asteroids
curl -fsSL https://space3d.dev/claude/AGENTS.md -o AGENTS.md
echo '@AGENTS.md' > CLAUDE.md

  6. Ask

    Claude can run, test and screenshot headless, so no window pops up. There is no MCP server yet; the space3d CLI is the tool surface.

    claude "Make a top-down asteroid shooter. Add tests, run space3d test, show me a screenshot."

For other agents

Everything on this page is plain HTML, and /claude/SETUP.md is the same text as Markdown. llms.txt indexes the docs; llms-full.txt is the README plus all docs in one file. The source is public: github.com/SpaceCorps/Space3d.

If something fails

  • space3d: command not found: add ~/.cargo/bin (Windows: %USERPROFILE%\.cargo\bin) to your PATH.
  • A compile error while installing: check that rustc --version is 1.98 or newer.
  • Anything else: run space3d doctor and open an issue with its output.
