Integration

Space3d for Claude Code

Give Claude the engine's rules and the build–test–look loop, and let it build the game. Everything lives in the repo under integrations/claude-code/.

  1. Install the plugin

    Adds the space3d-game skill: scaffold, the edit → test → screenshot loop, and the engine's hard rules (fixed tick, never block the frame, wasm-clean).

    /plugin marketplace add SpaceCorps/Space3d
/plugin install space3d@space3d

  2. Drop in the AGENTS.md

    curl -fsSL https://space3d.dev/claude/AGENTS.md -o AGENTS.md
echo '@AGENTS.md' > CLAUDE.md

    View the template · View the skill

  3. Ask

    space3d new asteroids --template 3d
claude "Make a top-down asteroid shooter. Add tests, run space3d test, show me a screenshot."

    Claude can run, test and screenshot headless, so no window pops up. There is no MCP server yet; the space3d CLI is the tool surface.
