Build games with Claude Code.

Space3d is a cross-platform 3D game engine in Rust — one codebase for desktop, the web, Android and iOS. Deterministic simulation, headless rendering and golden-screenshot tests make it a loop an AI agent can actually verify.

Quickstart

  1. Install (Rust 1.98+; no releases yet, so build from source): 
    cargo install --git https://github.com/SpaceCorps/Space3d space3d-cli
space3d doctor   # lists what is missing per platform and how to fix it
  2. Scaffold:
    space3d new my_game                      # a cube you move around
space3d new arena --template 3d          # physics playground
space3d new party --template multiplayer # server-authoritative netcode
  3. Run:
    cd my_game
space3d run          # desktop
space3d serve        # web, http://localhost:8080
space3d test         # input simulation + golden screenshots

Why it works with agents

Verifiable

Tests drive time with step_ticks(n) and input by simulation; visuals are checked against golden screenshots, headless.

Never steals focus

Agent and CI runs go to background/headless mode automatically — your desktop stays yours.

One build(app)

The same function runs on Windows, macOS, Linux, web, Android and iOS. Everything is a Plugin.

Fast renderer

wgpu, HDR and post effects, GPU particles, a million instances in a handful of draw calls.

Multiplayer built in

Prediction, interpolation, delta snapshots, a dedicated server and player service.

Never blocks the frame

I/O through space3d_tasks: tokio natively, wasm-bindgen-futures on the web.
